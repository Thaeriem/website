# Design Pass 3: Signal Garden

## Premise

The inner site becomes a compact signal garden: a living arrangement of nodes, pulses, and small instruments. It is less about a room and more about a responsive organism that reveals personal signals through touch.

This is the freshest departure from the chest. The chest can open into it, but the concept does not depend on cabinets, treasure, or RPG language.

## First Prototype Review

The first implementation became a labelled node diagram. It had circles and connecting lines, but the "living" part was mostly aesthetic. Selecting a node changed a note, which is normal website behavior with a network skin.

For the next pass, the garden must be a small organism or simulation. Nodes should have forces, memory, growth, decay, rhythm, attraction, or signal propagation. The visitor should see the system react before reading anything.

## Feeling

Quietly alive, tactile, minimal, luminous. A small system that breathes.

## Core Nodes

- `Seed`: origin and personal note.
- `Pulse`: tools, experiments, and making.
- `Drift`: visual taste, motion, atmosphere.
- `Gate`: contact and outbound paths.

## Interaction

The user tends, disturbs, or tunes the system. Touching a node should propagate through the garden: lines reroute, pulses change tempo, dormant marks wake up, nearby elements grow or dim, and the system keeps visible traces of the session. Dragging should change the network's behavior, not merely reposition a label.

## Taste Rules

- No generic network graph.
- No decorative particles without state.
- No vague "creative energy" language.
- Motion must communicate relationship or rhythm.
- Contact remains plain.
- No side panel as the primary content reveal.
- The organism should remain compelling with labels hidden.

## Next-Pass System Sketch

Start from one of these:

- A force-directed signal organism that grows trails from touched nodes.
- A garden where words bloom from pulses and then decay into marks.
- A tuning system where dragging changes rhythm, density, and visual weather.
- A living circuit where signals route through nodes and reveal traces only along active paths.

## Success Test

The visitor should say: "I touched a small living system that revealed a person."

They should not say: "I saw an abstract particle background with labels."
