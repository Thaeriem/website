# Design Pass 1: The Chest Room

## Premise

The island chest opens a small private room of personal artifacts. It is a cabinet/worktable hybrid: intimate, tactile, and edited. The visitor inspects four objects rather than browsing portfolio sections.

## First Prototype Review

The first implementation did not go far enough. It translated the room into a website layout: artifact cards on one side, content panel on the other, large title above. The concept said "cabinet," but the screen behaved like a styled selector.

For the next pass, the room must be built as a spatial or physical system first. Text and content should appear as consequences of touching objects, opening compartments, tuning instruments, or disturbing the room.

## Feeling

Workbench clarity, save-room calm, cabinet specificity, instrument feedback.

## Core Objects

- `Instrument`: software as a held tool.
- `Weather`: interface atmosphere and motion.
- `System`: rules, constraints, architecture.
- `Signal`: plain exits and contact.

## Interaction

The user manipulates artifacts, not navigation cards. Each object should have a physical or procedural behavior: open, rotate, spill, flicker, unfold, cast light, draw a path, rearrange nearby objects, or reveal a hidden surface. `Weather` should alter the room's whole visual behavior, not merely toggle a note.

## Taste Rules

- No project grid.
- No resume content.
- No card grid pretending to be a cabinet.
- No content panel as the main event.
- No full-screen terminal.
- No decorative dragging.
- Back stays outside the fiction.
- Signal stays intentionally plain.
- The room should still be interesting if all copy is temporarily removed.

## Next-Pass System Sketch

Start from one of these, not from a page layout:

- A cabinet face with doors, drawers, hidden compartments, and layered depth.
- A worktable where objects cast moving shadows and leave marks when touched.
- A small room rendered as a pseudo-3D scene with parallax, occlusion, and object focus.
- A mechanical display where objects feed a central instrument with light, text, or signal.

## Success Test

The visitor should say: "I found a strange little room of personal artifacts."

They should not say: "I found a portfolio menu with cool styling."
